# Paydown

Paydown is a Vite + React dashboard for tracking a floating-rate home loan in INR. It models the current payoff path, rate revisions, part payments, and alternate what-if scenarios from a fixed EMI / tenure-reduction perspective.

**Live:** [just-sampath.github.io/paydown](https://just-sampath.github.io/paydown/) (shows the sample loan)

## What It Tracks

- Dashboard summary for outstanding balance, months saved, interest saved, current rate, and next EMI.
- Month-by-month amortization schedule with rate-change and prepayment markers.
- Editable loan terms, floating-rate revisions and part payments, persisted in `localStorage` for the sample loan.
- Your own loan: enter it in Settings and it is kept encrypted with your passphrase on your device, never sent anywhere. Move it to another device with a link that carries only ciphertext.
- An optional private loan shipped only as a passphrase-encrypted file and unlocked in Settings (see below).
- What-if scenarios that layer hypothetical rate changes and prepayments over the current loan.
- Theme and palette preferences, also persisted locally.

## Calculation Model

The loan engine lives in `src/features/loan/loanEngine.ts`. It uses the reducing-balance EMI formula, keeps EMI constant after rate changes or part payments, and shortens or extends tenure based on the resulting balance. The calculation audit and source notes are in `docs/calculations.md`.

Everyone sees a fictional sample loan, defined in `src/config/sampleLoan.ts`:

- Principal: INR 45,00,000
- Original annual rate: 9.15%
- Original tenure: 240 months
- Start date: 2023-04-01

## Private Data Set

A real loan can ship with the site as `src/vault/set-a.vault.json`, encrypted in the browser-compatible WebCrypto format: AES-256-GCM with a PBKDF2-SHA256 key (1,000,000 iterations) and fixed-size padding. **Settings → Data on this device → Unlock set a** prompts for the passphrase. The plaintext lives only in the gitignored `.private/` folder, and every change goes through the passphrase-gated CLI:

```bash
bun run vault add-payment --date 2026-09-14 --amount 90000
```

See `docs/vault.md` for the format, threat model, CLI commands and the leak check. The same file covers "Your loan": how a visitor's own loan is encrypted in the browser and shared by link.

## Local Development

```bash
bun install
bun run dev        # start Vite on 127.0.0.1
bun run lint
bun run test
bun run build
bun run preview    # serve the production build
```

## Scripts

| Command | Purpose |
| --- | --- |
| `bun run dev` | Start Vite on `127.0.0.1`. |
| `bun run typecheck` | Type-check app and Vite config projects. |
| `bun run build` | Type-check, then build static assets into `dist`. |
| `bun run test` | Run Vitest tests. |
| `bun run lint` | Run ESLint with zero warnings allowed. |
| `bun run format` | Format source, root config, and docs files with Prettier. |
| `bun run format:check` | Check formatting without writing changes. |
| `bun run vault <cmd>` | Manage the encrypted private data set (passphrase prompt). |
| `bun run check:private` | Fail if plaintext loan data is tracked by git. |
| `bun run leak-check` | Search the tree, history, `dist/` or the deployed site for private loan figures. |
| `bun run deploy` | Legacy local `gh-pages` branch deploy path. The GitHub Actions workflow below is the preferred Pages deployment. |

## Project Structure

```text
public/                  Favicons and apple-touch-icon served as-is at the site root
src/app/                 App shell and localStorage helpers
src/components/          Shared layout, cards, primitives, and charts
src/config/              Fictional sample loan
src/features/loan/       EMI, schedule, impact, and aggregate calculations
src/features/vault/      Loan profile validation and passphrase encryption
src/vault/               Encrypted private data set (generated by the vault CLI)
scripts/                 Vault CLI, leak check, plaintext guard, icon generator
src/pages/               Dashboard, schedule, event editors, scenarios, settings
src/styles/              Tailwind and app-level CSS
tests/                   Vitest files mirroring the src/ tree
docs/calculations.md     Calculation audit and external source notes
docs/vault.md            Encrypted data set design and CLI
```

## Deployment

`.github/workflows/deploy-pages.yml` deploys every push to `main` to GitHub Pages. It installs with `bun install --frozen-lockfile`, runs the plaintext guard, lint, tests and the production build, then publishes `dist/`. In the repo settings, Pages must use GitHub Actions as its source.

The site is served under `/paydown/` (`base` in `vite.config.ts`). To serve it from a domain root instead, set `BASE_PATH=/` in the workflow.
